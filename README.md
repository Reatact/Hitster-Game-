# Hitster Custom

Digitale Hitster-Karten aus eigenen Spotify-Playlists.

**App:** die URL unter Settings → Pages

## Einrichtung
1. App im [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) anlegen (API: Web API).
2. Redirect URI: exakt die URL, die die App auf dem Einrichtungsbildschirm anzeigt.
3. Eigenen Spotify-Account unter „User Management“ eintragen.
4. Client ID in der App einfügen und verbinden.
